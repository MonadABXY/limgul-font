## 웹폰트 적용

HTML `<link>` 태그 또는 CSS `@import` 방식으로 폰트를 불러온 후 사용할 수 있습니다.

### `<link>`

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/MonadABXY/limgul-font/limgul.css" />
```

### `@import`

```css
@import url("https://cdn.jsdelivr.net/gh/MonadABXY/limgul-font/limgul.css");
```

### `폰트 패밀리로 사용`

```css
font-family: "Limgul12", sans-serif;
```

### `클래스로 사용`

```css
<div class="limgul12">림굴 12px</div>
```
